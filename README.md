# Mobile Workspace

Private workspace for mobile Claude Code sessions.

## Charyzma — trening komunikacji

`index.html` to samodzielna aplikacja webowa (bez zależności, działa offline):
14-lekcyjny kurs charyzmy, retoryki i small talku oparty na badaniach
(Arystoteles, Cialdini, Gottman, Voss, Rosenberg i in.).

Funkcje:

- **Lekcje** — pełna treść kursu z ćwiczeniami i złotymi zasadami,
  odhaczanie „przeczytane" i „ćwiczenie wykonane"
- **Quizy** — po 2 pytania sprawdzające pod każdą lekcją, z natychmiastową
  informacją zwrotną i statusem zaliczenia
- **Fiszki** — powtórka złotych zasad i technik (PREP, SBI, ARE, looping…)
  z prostym rozkładaniem powtórek
- **Dziennik treningu** — jedno zdanie notatki po każdym ćwiczeniu,
  przeglądane chronologicznie w osobnej zakładce
- **Postęp** — procent ukończenia, seria dni treningu, zaliczone quizy,
  liczba notatek i status każdej lekcji
- Postęp zapisywany lokalnie w przeglądarce (localStorage), tryb jasny i ciemny

Uruchomienie: otwórz `index.html` w przeglądarce (albo hostuj przez GitHub Pages).
